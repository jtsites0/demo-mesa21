# Mesa 21 — Projeto demonstrativo

Projeto fictício criado pela **JT Sites** para demonstrar uma presença digital expressiva para restaurantes.

## Conceito
- paleta quente em terracota, vinho e creme
- cardápio demonstrativo com preços fictícios
- direção visual gastronômica e editorial
- fluxo visual de reserva sem envio real de dados
- layout responsivo

> Mesa 21 é uma marca fictícia. Nenhum prato, preço, endereço ou reserva representa um restaurante real.

## GitHub Pages
Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**.

URL esperada: `https://jtsites0.github.io/demo-mesa21/`
